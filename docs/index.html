Shell configuration for zsh, bash and fish

Your shell setup, managed by commands.

wayu keeps your PATH entries, aliases, environment variables, encrypted secrets, scripts and plugins in one place, and compiles them into a single file your shell sources at startup. Add something with one command; every open shell picks up PATH changes at its next prompt.

$brew install dvrd/wayu/wayu
Watch the demo

zsh sources it in 9.2 ms (measured) no runtime dependencies MIT, written in Odin

zsh — ~/projects/api

Example session: wayu path add ~/.cargo/bin adds the directory to PATH; wayu alias add gs 'git status -sb' adds an alias; wayu const add OPENAI_API_KEY --run-only asks for the value with hidden input and stores it encrypted; wayu const list shows the secret as eight asterisks with source "wayu (run-only)".

How it works

          
You edit one file. wayu writes another. Your shell reads a third.

          
Settings you choose by hand stay in a TOML file you can keep in git. The entries you add from the command line live in a JSON store only wayu writes. Both compile into one generated init file.

        


        

          

            
You edit

            
wayu.toml

            
Shell, [tools] loaders, the prompt, script and secrets settings. Run wayu build after an edit, or let the next prompt rebuild it.

            
~/.config/wayu/wayu.toml


[tools]
zoxide = { kind = "evalcache", args = "init zsh" }
nvm    = { kind = "nvm" }

[prompt]
enabled = true
vi_mode = true

[secrets]
backend = "auto"

          


          

            
wayu writes

            
entries.json

            
PATH entries, aliases and constants from wayu path|alias|const and the TUI. Atomic writes, mode 0600, backed up first.

            
~/.local/share/wayu/entries.json


{
  "paths": [
    {"key": "cargo_bin", "dir": "$HOME/.cargo/bin"}
  ],
  "aliases": [
    {"name": "gs", "value": "git status -sb"}
  ],
  "env": [
    {"name": "GOPATH", "value": "$HOME/go"},
    {"name": "OPENAI_API_KEY", "secret": true}
  ]
}

          


          

            
Your shell sources

            
core.zsh

            
Straight-line code, regenerated after every change (zcompiled for zsh). Lazy loaders, the prompt and PATH sync are function definitions and hooks, not startup work.

            
~/.local/share/wayu/core.zsh (generated)


# === Environment ===
export GOPATH="${HOME}/go"

# === Secrets (encrypted store, per-session cache) ===
# fresh cache: source it; else `wayu secrets cache` once
[ -O "$_wayu_sc" ] && … && source "$_wayu_sc"

# === PATH (live-synced at each prompt) ===
_wayu_paths_apply <sig> ${HOME:+"${HOME}"'/.cargo/bin'}

# === Aliases ===
alias gs='git status -sb'

          

        

        
Your rc file gets one line, source "${WAYU_DATA_DIR:-${XDG_DATA_HOME:-$HOME/.local/share}/wayu}/init.zsh", which wayu init offers to add. bash and fish get init.bash and init.fish from the same entries. (Excerpts above are shortened.)

      

    


    
    

      

        

          

            
wayu script

            
Small tools in any language, already on your PATH.

            
Scripts get the same treatment as aliases: one command to create, list or remove, and a directory wayu manages.

          

          
    
            
  • wayu script new today --lang python writes a skeleton with the interpreter's absolute path as the shebang, opens $EDITOR, then links it into bin/, which is first among wayu's PATH entries.
    • 
            
  • Swift is compiled with swiftc -O. wayu build rebuilds only scripts whose source hash changed.
    • 
            
  • wayu script import adopts scripts you already have in ~/.local/bin or ~/bin, skipping binaries, symlinks and package-manager launchers. --dry-run shows what it would do.
    • 
            
  • wayu doctor reports stale or broken scripts and bin/ entries without a source.
    •

  • python

Encrypted constants

            
API keys out of your dotfiles, without slowing startup.

            
A secret is a constant whose value is stored encrypted. Your config, the generated files and the backups only ever hold its name.

          

          
    
            
  • wayu const add NAME --secret reads the value with hidden input, so it stays out of argv and history, and encrypts it with ChaCha20-Poly1305.
    • 
            
  • The master key lives in the macOS Keychain, the Secret Service on Linux, or a 0600 key file: [secrets] backend.
    • 
            
  • Startup sources a per-session cache (0600, in your runtime dir), decrypted once and then loaded without forking. Five secrets added 0.6 ms to zsh startup in our measurement.
    • 
            
  • Run-only secrets (--run-only) are never exported to your shell. wayu secrets run NAME -- cmd hands them to that one command.
    • 
            
  • Masked everywhere: const list, search, the TUI and dry runs show ********; const get NAME prints the value when you ask for it.
    •

Also included

          
The rest of a shell setup.

        

        

          
Native zsh prompt [prompt]
Opt-in. Directory, git branch read from .git/HEAD without running git, project context detection, an async right prompt with the changed-file count, and vi-mode with a mode indicator.

          
Plugins wayu plugin
Search a built-in registry or install from a git URL. Enable, disable, set load priority, resolve dependencies, and see conflicts with your own aliases and constants.

          
Tool loaders [tools]
Cache the output of zoxide init zsh and similar until the binary changes, or load nvm, conda and sdkman only when you first call them.

          
Health check wayu doctor
Checks PATH entries, config, scripts, plugins, backups and the secrets store. Exits 78 on any error, so it can gate CI; --fix repairs what it can.

          
Full-screen TUI wayu
Run it with no arguments to browse, filter, add and delete PATH entries, aliases and constants, and to manage plugins, backups and hooks. Vim keys and arrow keys.

          
Scriptable CLI --json
Never prompts. Lists, search and doctor print JSON; exit codes follow sysexits.h; destructive actions need --yes; --dry-run previews any write.

          
Live PATH in open shells
A prompt hook re-reads the PATH list when it changed, so wayu path add reaches every open zsh, bash and fish at its next prompt.

          
Backups wayu backup
Each file is backed up before its first write in a run; the last five are kept. Restore by index with wayu backup restore.

Startup time

          
Mostly the time it takes to start the shell.

          
Everything is precomputed into one file at write time, so a new shell runs straight-line code instead of calling wayu.

        

        

          

            
zsh 5.9

            
empty shell, zsh -f -c :3.6 ms

            
source init.zsh9.2 ms

            
interactive, with compinit14.6 ms

            
interactive + [tools] + prompt15.3 ms

          

          

            
bash 3.2

            
empty shell, bash --norc -c :2.0 ms

            
source init.bash4.3 ms

          

        

        
Mean of 40 runs with hyperfine, measured with tests/benchmark/startup.sh: 21 PATH entries, 60 aliases, 20 constants, warm caches, on an Apple M1 Max (macOS). The secrets figure is a separate hyperfine run (50 runs, zsh -f -c 'source init.zsh') in the small demo home built by docs/demo/setup.sh, before and after adding five session secrets: 8.1 → 8.7 ms. Your numbers will differ; run the script, or wayu build profile to time each section of your own init.

      

    


    
    

      

        

          
Install

          
Three commands to a working setup.

          
Prebuilt for macOS arm64 and Linux x86_64. Other platforms build from source.

        

        
    
          
  1. 
            
    
              
    Install with Homebrew
    
              
    

    brew tap dvrd/wayu
brew install wayu
    
                
              
    
            
    
          
    2. 
          
  2. 
            
    
              
    Create the config and wire up your shell
    
              
    Creates ~/.config/wayu/ and ~/.local/share/wayu/, and offers to add the source line to your rc file. Use --shell bash or --shell fish for another shell.
    
              
    

    wayu init
    
                
              
    
            
    
          
    3. 
          
  3. 
            
    
              
    Add your first entries
    
              
    

    wayu path add ~/.cargo/bin
wayu alias add gs 'git status -sb'
wayu const add OPENAI_API_KEY --secret
wayu doctor
    
                
              
    
            
    
          
    4. 
        


        

          Build from source
          

            
Needs the Odin compiler at the release named in .github/odin-release. ./build_it install puts the binary in ~/.local/bin and runs wayu init.

            


git clone https://github.com/dvrd/wayu && cd wayu
odin build build -out:build_it && ./build_it install

            

          

        

        

          Upgrading from 5.x
          

            
6.0.0 moves PATH entries, aliases and constants from wayu.toml to entries.json in the data dir, and changes the rc line. Nothing is converted automatically: the steps are in docs/UPGRADING.md.
